# AIAA project images

The six existing images keep their original filenames and prescribed order. See [the AIAA image list](../../../../docs/AIAA_IMAGES.md) for the exact order and approved captions; do not rename these files to add numeric prefixes.

Upload additional public photos or diagrams here using JPG, JPEG, PNG, WebP, or AVIF files. The next GitHub Pages build includes them automatically after the prescribed set, in natural filename order.

Optional alt text, captions, and credits go in `src/gallery-captions.json`, under `aiaa` and then the exact filename. Preserve team ownership and credit contributors when appropriate.
