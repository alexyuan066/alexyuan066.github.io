# AIAA project images

Upload public project photos or diagrams here using JPG, JPEG, PNG, WebP, or AVIF files. The next GitHub Pages build includes them automatically. Number descriptive filenames to choose their order, such as `01-feed-system.png`.

Optional alt text, captions, and credits go in `src/gallery-captions.json`, under `aiaa` and then the exact filename. Preserve team ownership and credit contributors when appropriate.
