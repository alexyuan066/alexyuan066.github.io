# Ultrasonic project images

Upload public project photos or diagrams here using JPG, JPEG, PNG, WebP, or AVIF files. The next GitHub Pages build includes them automatically. Number descriptive filenames to choose their order, such as `01-treatment-concept.png`.

Optional alt text, captions, and credits go in `src/gallery-captions.json`, under `ultrasonic` and then the exact filename. Do not upload confidential work or private sponsor information.
