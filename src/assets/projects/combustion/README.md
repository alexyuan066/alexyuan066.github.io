# Combustion research images

Upload public research photos or diagrams here using JPG, JPEG, PNG, WebP, or AVIF files. The next GitHub Pages build includes them automatically. Number descriptive filenames to choose their order, such as `01-test-stand.png`.

Optional alt text, captions, and credits go in `src/gallery-captions.json`, under `combustion` and then the exact filename. Use only material intended for public sharing and preserve research-team attribution.
